3. 親波構造やゾーン応用とは？

今のv7.6.4は、ざっくり言うと、

現在足の時間軸におけるMTA検出インジケーター

です。

次にやるなら、方向性は3つあります。

A. 親波構造

今のピボット6本は、やや細かい波です。
親波構造では、もっと大きな波を別で見ます。

例：

小波：左右6本ピボット
親波：左右12本、18本、24本ピボット

そして、

小波は上昇
でも親波は下降

みたいな状態を判定します。

これはかなり実戦向きです。

B. ゾーン応用

今はMTAゾーンを表示しているだけです。
次は、そのゾーンを使って判断できます。

例：

価格が押し安値MTAゾーンに接近
ゾーン内で反発
ゾーン割れで上昇終了
ゾーンを背にエントリー候補

つまりMTAを「見るだけ」から、
条件判定に使う段階です。

C. アラート・検証用サイン

次に実用化するならこれも強いです。

MTAゾーン接触
MTAゾーン実体抜け
MTA対応高値更新
MTA対応安値更新
トレンド終了
トレンド未確定

これらにアラートを付けられます。
